The website I tested

SauceDemo is a small online shop that exists only for practising testing. Nothing on it is real, so tests can log in, fill carts and place orders without any risk.

SauceDemo (Swag Labs)

A demo shop made by Sauce Labs with the screens every web shop has: login, a product list with sorting, a cart, a checkout form and a logout menu.
